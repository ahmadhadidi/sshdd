# TODO

Add items by saying **"todo:"** or **"add to todo"**. Every item is a note in `todo/` with a permanent number (`#12`): numbers are never reused or changed.

**Board:** Inbox → In progress → Review → Done. Drag a card to change its status; dragging a Review card to Done approves it. Claude moves cards with the todo-tables skill's `todo.py`, which dates every move in the note's Updates.
